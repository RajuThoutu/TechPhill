# Pega + Azure AI: Orchestrating value-first automations

Combining the process orchestration power of Pega with the cognitive intelligence of Azure OpenAI creates a potent enterprise stack.

## Architecture Pattern

1.  **Pega**: Manages the lifecycle, state, and human-in-the-loop governance.
2.  **Azure OpenAI**: Provides the generative capabilities for summarization, extraction, and drafting.

## Value-First Design

Instead of "AI everywhere," we focus on high-friction points where AI provides measurable value:
*   Email triage and routing.
*   Complex case summarization for reviewers.
*   Generating customer-friendly responses from technical logs.
